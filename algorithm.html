LOCAL-FIRST SYNCHRONIZATION ALGORITHM

ローカルファースト双方向同期パイプライン

「端末ローカルで即座に0msで画面更新し、ユーザーを待たせずに非同期でクラウドへ同期する」設計アルゴリズムの流れです。

01

UI操作 ＆ 即時ローカル書き込み

タスク追加や完了時にlocalStorageへ即時JSON文字列化して保存。ユーザーはラグを一切感じません。

localStorage.setItem(key, val);
02

Set キューイング ＆ デバウンス

変更キーを pendingKeys.add(key) で重複排除。500msのタイマーをリセットし、連続操作を1回の通信に集約。

clearTimeout(syncTimer);
syncTimer = setTimeout(..., 500);
03

Supabase バッチ Upsert

ログイン中のUUIDを確認し、user_data テーブルに onConflict: "user_id, data_key" で一括保存。

client.from("user_data").upsert(...)
04

クラウド引き込み ＆ 差分検知

ログイン時や別端末変更時に pullCloudData() を実行。ローカル文字列と異なる場合のみ上書き更新。

if (localStorage[key] !== cloudVal)
05

カスタムイベント発火 ＆ 自動再描画

データ更新を検知すると myNoteDataSynced を発火し、各画面の renderAll() を自動呼び出し。

window.dispatchEvent("myNoteDataSynced")

HABIT STREAK & RESET ALGORITHM

習慣タスク日次リセット ＆ ストリーク判定ロジック

日付を跨いだときに、継続日数を増やすかリセットするかを決定するステートマシンアルゴリズムです。

01

日付キー比較 (checkDailyReset)

起動時に保存された habitLastDate と今の日付 getTodayKey() を比較。

diffDays = getDaysDiff(lastDate, today);
02

分岐 A: 同日アクセス (diffDays === 0)

今日すでにアクセス済みのため、リセット処理はスキップ。既存の達成状態をそのまま維持。

return false; // 何もしない
03

分岐 B: 翌日アクセス (diffDays === 1)

昨日アクセスあり！達成済タスクは streak++、未達成タスクは streak = 0。前日を履歴に保存し未完了化。

completed.forEach(t => t.streak++);
04

分岐 C: 2日以上放置 (diffDays >= 2)

昨日タスクを実施しなかったため、全タスクの streak = 0 にリセット。継続記録は途切れます。

allTasks.forEach(t => t.streak = 0);

KADAI CLUSTERING & PROGRESS ENGINE

課題週次クラスタリング ＆ 達成率計算

締切日時に基づいて「今週」「来週」「再来週以降」の3グループに自動クラスタリングし、達成率プログレスバーを動的生成するアルゴリズムです。

01

タイムスタンプ昇順ソート

全課題の締切日時をDateオブジェクト化し、近い順にクイックソート。

tasks.sort((a,b) => new Date(a.deadline) - new Date(b.deadline));
02

月曜起点週キー算出 (getWeekKey)

基準日（今日・来週・課題締切）の週の月曜日日付をYYYY-MM-DD形式で一意にハッシュ化。

d.setDate(d.getDate() - dayOfWeek + 1);
03

3分割クラスタリング判定

週キーの等値判定により thisWeek, nextWeek, later の3配列に分配。

if (wk === current) thisWeek.push(t);
04

達成率プログレス計算式

完了数と未完了数からパーセンテージを四捨五入計算し、UIの幅アニメーションを更新。

Math.round((comp / (act + comp)) * 100);

NOTIFICATION SCANNER ENGINE

全方位通知スキャン ＆ 優先度合成アルゴリズム

アプリ起動時や定期インターバルで全データを一括巡回し、締切前日・当日・習慣リマインドをリアルタイム抽出するアルゴリズムです。

01

マルチソース・スキャン

「カレンダー予定」「課題締切」「通常タスク」「毎日習慣」「誕生日」の5系統を並行巡回。

scanSchedules(), scanKadai(), ...
02

3日以内 ＆ 当日日付フィルタ

todayKey および in3DaysKey の範囲内にある未完了アイテムのみを抽出。

if (itemDate >= today && itemDate <= in3Days)
03

既読ID差分フィルタ

readNotificationIds 配列に含まれる既読通知を除外し、未読バッジ件数を確定。

!readIds.includes(notification.id)
04

Web Notification API 発火

ブラウザ通知権限が許可されている場合、システムトレイへデスクトップ通知を即時送出。

new Notification("MyNote", { body });
REPORT SYNTHESIS & EXPORT ENGINE

報告書自動集計 ＆ ドキュメント生成

過去1ヶ月・3ヶ月の完了実績やスケジュールを抽出し、6種類の美しいテンプレートに自動整形してWord/Markdown出力するエンジンです。

01

データソース抽出

カレンダー予定・課題・タスクから実績データを集約し、期間（1/3ヶ月）でフィルタリング。

schedules.filter(s => s.date >= rangeStart)
02

文字数カウント＆サニタイズ

改行・空白を除外した純粋文字数のリアルタイム算出とXSS防止のエスケープ処理。

text.replace(/\r?\n/g, "").length
03

テーマ別CSS動的注入

クラシックブルー、ミッドナイト、エディトリアルなど6種類のデザインCSSをプレビューへ即時適用。

applyTheme(REPORT_THEMES[selected])
04

Word(.doc) / Markdown出力

HTML Blobを作成し、MIMEタイプ application/msword としてブラウザダウンロード。

new Blob([docHtml], { type: "application/msword" })
